# Pre-launch UX review — 2026-09-03

The page was walked as a café owner would walk it — on a phone first (390 and
360 wide), then on a desktop — with the enquiry form as its one job. Rendered
from `src/index.html` with every remote request blocked, so photographs are
colour blocks in the screenshots; nothing below depends on them.

Method: the `ui-ux-pro-max` quick reference (§1 accessibility, §2 touch,
§3 performance, §8 forms) and the `taste-skill` redesign-preserve protocol
(audit first; slugs, anchors, nav labels, field order and copy voice stay).
Both skills now live in `.claude/skills/`.

Ranked by what it costs in enquiries. Fixed items live in `tools/patch_ux.py`
unless another file is named. `src/index.en.html` and `i18n/` are untouched;
`i18n/strings.en.json` is byte-identical before and after.

## Left alone — taste, or Tom's call

- **Four names for one destination**: "רוצים להתחיל" (nav), "רוצה מחירון"
  (hero), "בקשת שיתוף פעולה" (form), "בואו נדבר" (section). One name through
  the flow converts better; the wording is brand voice, so it is Tom's.
- **The hero is a collection carousel**, not a value proposition, and the H1 is
  screen-reader only. What GT is and for whom first appears on screen two.
  A design decision, not a defect.
- **Placeholders are the only labels** on the form. Visible labels mean eight
  new strings and a renumbered catalogue; the fields are few and the
  placeholders clear, so left.
- **12px eyebrows with wide tracking, 11px kickers, emoji bullets** — the
  design's voice.
- **Footer "אינסטגרם · פייסבוק · יוטיוב" is text, not links** — needs the real
  URLs from Tom; a guessed link is worse than none.
- **No photographs in About** — B4 in `PUBLISH.md`, unchanged.
